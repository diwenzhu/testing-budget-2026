The two-week rule. A project counts as a test for 14 days after it launches. A Testing End date from the sheet is used only when it falls inside that window (a test that ended early); later end dates are capped — so Press On, launched 3/31, is measured 3/31–4/13 rather than through 6/7. This is what makes these figures lower than earlier versions.

Reading this

  • New topics are the expensive product. ~$2,010 per round and 2.00 rounds to land one — about 4× the all-in cost of a localization ($1,030). They only appear in Version B, because every new-topic test so far is filed as Other.
  • Version A understates topic testing. Version A shows no New-topic line at all — not because none ran, but because none are classified as Test. If topic tests are meant to be tests, Version B is the truer picture.
  • The backlog will not clear at current pace. Both versions would need roughly 3× the demonstrated launch rate to finish everything still on the plan. The realistic number is the left-hand scenario; the right-hand one is a ceiling.
  • BigQuery restates history. The same campaign over the same closed window can change between refreshes (one dropped 25% between July and August). Treat these as accurate to within a few percent, not to the dollar.
  • Rounds are provisional. Round counts come from repeat entries per program-language; tests still marked Iterating may add rounds and push the cost-to-land figures up.
